# 요구사항

## 서비스

- 이름: 빵지순례
- 한 줄 소개: 우리 동네 빵집에서 만난 오늘의 빵을 사진으로 남겨요
- 종류: 사진 피드 SNS (주제: 동네 빵집 기록)

## 게시물 항목

| 항목 | 설명 |
| --- | --- |
| id | 게시물 고유 번호 |
| author | 작성자 |
| content | 본문 글 |
| images | 사진 목록 (1~10장) |
| created_at | 작성 시각 |

## 화면

- 피드 화면 하나만 있음
- 게시물 카드가 위에서 아래로 쌓임
- 휴대폰 폭(가로 430px 이하) 기준

## 캐러셀 상태

| 상태 | 보여주는 방식 |
| --- | --- |
| 사진 1장 | 캐러셀 없이 사진 한 장만 보여줌 |
| 사진 여러 장 (2~10장) | swiper 캐러셀로 옆으로 넘겨 봄 |

## 무한 스크롤 상태

| 상태 | 문구 |
| --- | --- |
| 처음 불러오는 중 | 빵을 굽는 중이에요… |
| 더 불러오는 중 | 다음 빵을 꺼내는 중… |
| 더 없음 | 오늘 빵은 여기까지예요 |
| 오류 | 빵이 타버렸어요. 다시 시도해 주세요 |

## 분위기

레트로 동네 빵집: 연분홍 바탕에 분홍·민트·노랑 파스텔, 동글동글한 카드와 정돈된 상단바로 단정하면서도 귀여운 느낌

## 디자인 규칙

기준 시안: `prototype/feed-d.html` (D안 — C안의 파스텔 색 + A안의 상단바)

### 색

| 이름 | 값 | 쓰는 곳 |
| --- | --- | --- |
| 바깥 배경 | `#bfe8d6` | 휴대폰 화면 바깥 |
| 화면 배경 | `#fff3f0` | 화면 전체, 상단바 |
| 흰색 | `#ffffff` | 카드, 상태 상자, 사진 점(현재 아님), 시간 태그·다시 굽기 글자 |
| 분홍 | `#ee7f9f` | ✳ 기호, 현재 사진 점, 로고 윗면, 더 없음 그림자 |
| 진한 분홍 | `#c94f74` | 더 보기 글자, 상태 예시 라벨, 오류 글자·테두리 |
| 노랑 | `#ffd66b` | 로고 빵, 아바타, 사진 번호 배지, 더 없음 배경 |
| 연분홍 | `#fde3ea` | 작성자 태그, 더 보기 버튼, 오류 배경, 사진 자리 |
| 민트 | `#6ccaa6` | 시간 태그, 카드 그림자, 다시 굽기 버튼, 불러오는 중 점선 |
| 코코아 | `#4a3535` | 기본 글자, 모든 테두리 |
| 흐린 코코아 | `#8f6f6f` | 한 줄 소개 |

- 불러오는 중 점 3개는 분홍 → 노랑 → 민트 순서

### 글꼴

외부 글꼴 파일 없이 기기에 설치된 글꼴만 쓴다.

| 용도 | 글꼴 (앞에서부터 있는 것 사용) |
| --- | --- |
| 본문 | Apple SD Gothic Neo, Malgun Gothic, system-ui |
| 강조 (태그, 버튼, 상태 문구, 사진 번호, 아바타) | HY견고딕, HYGothic-Extra, Black Han Sans, 없으면 본문 글꼴 |
| 명조 (한 줄 소개, 기울임) | Nanum Myeongjo, AppleMyungjo, Batang |

- 자간: 전체 `-0.03em` (버튼 포함), 서비스 이름만 `-0.05em`
